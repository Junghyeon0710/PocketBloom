Pocket Bloom의 Sunlit Garden UI를 적용한 새 테스트 배포본입니다. 광고는 꺼져 있고 인앱결제는 없습니다.

2026-10-05 선택 시안에 맞춰 수채화 정원과 고양이 홈, 크림색 카드, 세이지 보드·파스텔 꽃 블록, 한국어·영어 UI와 글꼴을 교체했습니다. README 스크린샷과 플레이 하이라이트도 새 UI로 갱신했습니다. 이전 `v1.0.0-preview`는 보존합니다.

GitHub 배포 태그는 `v1.0.1-preview`이며 APK 내부 버전은 기존 테스트 설정 `1.0.0` / versionCode `1`을 유지합니다. 스토어용 출시 서명과 버전 코드 갱신은 별도 출시 준비 단계입니다.

- Android: Android 8.0(API 26) 이상 ARM64, 테스트용 debug 서명 APK입니다. 실제 단말 설치·플레이 검증은 아직 완료하지 못했습니다.
- Windows: ZIP을 모두 푼 뒤 `PocketBloom.exe`를 실행합니다. Windows 빌드 성공과 에디터 플레이는 확인했으며, 패키지 직접 조작 검증은 별도입니다.
- StoreKit: 스토어 배너·아이콘·한국어/영어 소개 문구입니다.
- Highlight: 실제 Unity 에디터 플레이를 녹화하고 자막·컷 편집한 약 30초 영상입니다. Android 단말 촬영이 아닙니다.

규칙·광고 보상 코드 테스트 13개가 통과했고, 36단계 승리 경로·UI·가상 터치와 APK 구조·16KB 정렬을 확인했습니다. 광고 계정, 실제 동의 흐름, 단말 광고 검증, 출시 서명과 스토어 등록은 아직 남아 있습니다. 게임 기획서와 검증 기록은 저장소의 `Docs`에서 확인할 수 있습니다.
