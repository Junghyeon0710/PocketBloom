# Sunlit Garden UI 적용

2026-10-05에 사용자가 첨부한 [선택 시안](SelectedReference.png)을 기준으로 홈과 플레이 화면을 구현했습니다. 이전 A/B 혼합 제안보다 이 선택 시안이 우선합니다.

| 화면 | 구현 |
|---|---|
| 홈 | 수채화 정원과 잠자는 고양이, 초록·코랄 로고, 씨앗 배지, 설정 아이콘, 큰 여행 시작 버튼, 오늘의 정원·끝없는 정원 카드, 나의 정원 |
| 플레이 | 크림색 점수·목표·남은 수 패널, 세이지색 8×8 보드, 파스텔 꽃 블록, 세 조각 받침, 한 수 뒤로·힌트·새 조각 |
| 단계·컬렉션·설정·팝업 | 같은 크림색 표면과 짙은 녹색 글자, 기존 단계·성장·언어·도구 기능 연결 |

`정원 여행 01 / 36` 버튼으로 단계 목록을 열 수 있습니다. 진행 중인 한 판이 있으면 큰 시작 버튼이 이어하기로 바뀝니다. 점수·목표·씨앗·남은 수는 실제 저장 데이터와 규칙을 표시합니다. 시안 속 예시 점수나 블록 배치를 게임 데이터에 덮어쓰지 않았습니다.

실제 적용 화면은 [홈](../Media/Screenshots/home.png)과 [플레이](../Media/Screenshots/gameplay.png), [하이라이트](../Media/README.md)에서 확인할 수 있습니다.

## 정렬과 목표 달성 화면 보완

카드 삽화의 `preserveAspect`가 좌상단 pivot을 기준으로 이미지를 배치하던 문제를 수정했습니다. 중앙 pivot과 Sprite의 투명 패딩을 함께 보정하여 오늘의 정원·끝없는 정원의 실제 렌더링 영역을 카드 중심에 맞춥니다. 제목도 카드 중앙에 놓고 화살표는 별도 끝 여백에 배치했습니다.

홈 버튼, 플레이 점수 패널·보드·조각·도구, 여행·컬렉션·설정의 좌우 기준선을 44/676으로 통일했습니다. 설정은 항목명과 ON/OFF 상태를 별도 열에 배치하며, 여행의 별 기록은 꽃 표시로 구성합니다. 안내 팝업은 문구의 실제 높이에 맞춰 여백과 버튼 위치를 계산합니다.

성공 팝업에는 [새 고양이 꽃다발 삽화](VictoryArtPrompt.md), 이번 판의 획득 꽃, 점수 카드, 씨앗 보상과 다음 정원 버튼을 배치했습니다. 짧은 카드 등장·점수 집계·꽃잎 연출은 표시만 바꾸며 게임 결과와 보상 계산은 그대로입니다. 움직임 줄이기 설정에서는 애니메이션 없이 최종 값을 즉시 표시합니다.

`Tools/VerifyVisualLayout.cs`는 한/영 × 세 비율 × 화면·팝업 12종의 72조합을 검사합니다. 글자 잘림 외에 실제 텍스트 높이, 버튼 경계, 삽화 메시 중심, 결과 카드 중심과 동작 감소 표시를 검사합니다. 마지막 단계와 일일 결과는 표시용 상태 fixture로 구분하며 실제 플레이 영상은 정상 입력과 규칙으로 촬영합니다.

## 자산과 구현

- 내장 ImageGen: `Resources/Sunlit`의 홈·플레이 배경, 로고, 달력·표지판·정원 책 삽화와 성공 팝업 꽃다발 7개. [기존 제작 프롬프트](ImageGenPrompts.json), [새 팝업 프롬프트](VictoryArtPrompt.md)와 선택 시안을 보존했습니다. 원본은 Codex 생성 이미지 보관함에도 유지합니다.
- uGUI/TextMeshPro: 버튼·문자·점수·보드·드래그 입력. `BloomSunlitUI.cs`가 배치를 구성하고 `BloomGraphic.cs`가 둥근 표면과 꽃 블록을 그립니다. `BloomIcon.cs`는 외부 아이콘 팩 없이 작성한 아이콘 메시입니다.
- 글꼴: 기존 OFL Noto Sans KR 가변 폰트가 Unity에서 Thin으로 읽히는 문제를 600 굵기의 정적 폰트 `PocketBloomSans-SemiBold.ttf`로 해결했습니다. 원본과 라이선스를 유지하고 변환본 이름을 변경했습니다.
- 안전 영역: 기존 720×1280 논리 화면을 안전 영역에 균일하게 맞추는 방식과 75픽셀 보드 간격을 유지했습니다. 배경 이미지에는 버튼 글자를 넣지 않아 한/영 전환과 터치 입력이 가능합니다.

글꼴을 재생성하려면 `fonttools==4.66.1`을 설치하고 `python Tools/BakeSunlitFont.py`를 실행합니다. 정적 인스턴스 생성 방식은 [fontTools 공식 문서](https://fonttools.readthedocs.io/en/latest/varLib/instancer.html)를 따릅니다. Unity의 `Pocket Bloom > Bake Sunlit Garden Font` 메뉴는 새 TMP 자산을 생성하는 최초 작업용이며 이미 존재하는 자산을 덮어쓰지 않습니다.

## 확인 범위

컴파일, 한/영 화면 배치, Input System 가상 터치, 정상 규칙을 통한 목표 달성·이어하기·도구·저장 복원을 확인합니다. 실제 결과 파일은 [검증 기록](../Validation/README.md)에 있습니다. 스크린샷과 영상은 에디터에서 실행한 게임이며 Android 실기기 화면은 아닙니다.

실제 광고 계정과 단말 테스트는 아직 준비되지 않아 광고는 꺼져 있습니다. 인앱결제는 없습니다.
